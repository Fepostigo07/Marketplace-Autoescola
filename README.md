# 🚗 Marketplace para Instrutores de Autoescola

> Uma plataforma para conectar alunos em processo de habilitação a instrutores de trânsito autônomos, simplificando a busca, o agendamento e a gestão de aulas práticas.

## 📖 Sobre o Projeto
Com as recentes flexibilizações no processo de habilitação, surgiu a oportunidade para instrutores atuarem de forma autônoma. Este software tem o objetivo de ser o ecossistema digital que une as duas pontas: alunos que buscam aulas avulsas/reforço e profissionais credenciados que desejam gerenciar sua própria agenda.

### ✨ Principais Funcionalidades (MVP)
- **Onboarding Inteligente:** Validação automatizada de CNH e credencial do Detran utilizando OCR (Reconhecimento Óptico de Caracteres).
- **Busca por Geolocalização:** Alunos encontram instrutores disponíveis em um raio de até 5km.
- **Gestão de Agendamentos:** Sistema de bloqueio de horários e máquina de estados para o ciclo de vida da aula (Pendente, Confirmada, Em Andamento, Concluída).
- **Sistema de Reputação:** Avaliações bidirecionais (1 a 5 estrelas e comentários) para garantir a qualidade e segurança da rede.
- **Comunicação Segura:** Chat interno liberado apenas após a confirmação da aula, com filtros de segurança.
